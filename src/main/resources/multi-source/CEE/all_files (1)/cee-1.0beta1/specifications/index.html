CEE Overview

This document provides a high-level overview of CEE along with details on the overall architecture and an overview of each of the CEE components.

CEE Profile

The CEE Profile allows for the improved interpretation and analysis of event data by allowing users to define how events are structured and what data they provide.

CEE Log Syntax (CLS)

CEE Log Syntax (CLS) describes the requirements for encoding and decoding for a Common Event Expression (CEE) Event, and provides encoding declarations for XML and JSON event records.

CEE Log Transport (CLT)

CEE Log Transport (CLT) provides the technical support necessary for a secure and reliable log infrastructure. It defines a listing of requirements conformant log transports must meet as well as transport mappings that define standard methodologies for transmitting CEE Event Records over certain protocols.

Terminology

List of event-related terminology as used by CEE.

CEE Core Profile

The CEE Core Profile defines a CEE Profile meant for use by the entire log management community. It includes a field dictionary and taxonomy that are generally useful for all types of event reporting.
