CHANGELOG1.0-beta1

Describes the changes that were made to this specification since the alpha release of CEE 1.0.

Architecture and Data Model Changes

  • Removed concept of augments
  • Simplified Profile and Event model
  • Added Requirements and Compatibility section to Overview

Specification Changes

Profile

  • Complete rewrite to simplify Profile and Event model

CLS

  • Rewrite of CEE Event section to include visual data model diagram and reference to validation mechanisms
  • Added Field Names section to specify valid CEE Field Names (inline vs. structured in particular)
  • Expanded Field Types section to specify field types external to XML Schema types
  • Updated ABNF definition of CEE JSON Event
  • Changed some JSON encoding specifications
  • Updated ABNF definition of CEE XML Event
  • Removed paragraph about validation against XSD
  • Added paragraph about optional type annotations
  • Updated all examples per above changes

CLT

  • Removed references to augment
  • Added '@' prefix to cee indicator in Syslog transport
  • Removed outer "Event" object from JSON example in Syslog transport
